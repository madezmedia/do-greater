How to build a proposal quickly

1. Start from a template

Pick the lane above. Start with the matching collateral in Collaterals so you don't rebuild copy every time.

2. Tune the opp

Replace [ORGANIZATION], [TRACK], [VENUE], and [COHORT] with the actual deal; keep the program facts from About/Programs as supporting bullets.

3. Send for review

Route for internal review, then send from the appropriate proposal channel. Update the opportunity log after send.
